# `shared/components/ui/`

Componentes generados por el CLI de **shadcn/ui** (`pnpm dlx shadcn@latest add …`,
tarea `frontend.md §1.3`). Son código del repo: se editan libremente.

Al agregarlos, reescribir los imports que el CLI deja con alias `@/` a rutas
**relativas** (`arquitectura-frontend.md §6`). El `tsconfig` no define `paths`.
